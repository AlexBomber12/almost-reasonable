# Finite research exhaustion feedback

The native authority journal can be exhausted by independently admitted operator
and autonomous operations while the public application's local count is smaller.
Native admission remains authoritative. It now distinguishes a spent aggregate
allowance from a duplicate operation without reserving or calling the provider.
Public accounting spans earlier profiles for the same account; private accounting
retains the existing per-profile scope. Previously reserved operation IDs still
return `duplicate_operation`, including after an uncertain provider result.

`allowance_exhausted` is a generic failure response with exactly zero attempts,
no usage and no report. The public application retains a fixed non-content marker
in its failed research operation and stops offering research for that exact
profile digest. This survives ordinary database reopening. Existing accepted
reports remain untrusted evidence available to later decisions; public dialogue,
mission choices, publication proposals and deliberate silence remain possible.
No opinion change or publication is required.

The first request after external consumption may receive this denial; this is
feedback rather than a claim of proactive cross-process reservation. An expired,
revoked or replaced authority still follows its existing guards. No journal,
counter, authorization, deadline or budget is reset or renewed. Old failures are
not replayed or retrospectively relabelled. Deploy app and worker from a coherent
reviewed candidate; older decoders safely reject the new terminal category.

Regressions exercise actual local IPC and SDK request assembly with fake providers,
including a report followed by external consumption and exhaustion. They establish
the connected control path, not semantic quality or real human/public acceptance.
